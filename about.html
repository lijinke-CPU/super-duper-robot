壹书房为什么叫「拾光」

「拾光」，取「拾起时光」与「书页间落满星光」之意。我们在书页间拾取星光，在银幕上打捞时光——那些被一部书、一部电影照亮的瞬间，都值得被小心收藏。

愿你也在这里，捡到属于自己的那束光。—— 房主人

叁营造手记（制作说明）

本站为《计算机基础》课程设计作业，采用以下方式完成：

01

工具

VS Code 编写代码 · AI 辅助生成文案与插画 · Photoshop 式后期修图（CSS 滤镜统一色调）

02

技术

纯 HTML / CSS / JavaScript 手写实现，无第三方框架；页面间一律使用相对路径链接

03

设计

莫兰迪色调 · 衬线字体 · 简约留白，追求「高级而安静的文学感」

04

发布

全部页面托管于 GitHub Pages，访问形如 https://***.github.io/***/

肆一点声明

站内所有推荐语与鉴赏文字为原创撰写；插图由 AI 生成；所荐书目与影片信息仅供学习交流。若你因这份书单翻开了一本好书、看了一部好电影，就是这间书房最大的心愿。
